CC BY-ND4.0 permits sharing the licensed original with attribution and permits producing adapted material without sharing it. We will therefore keep any modified waveform/label arrays local and reproduce them using code rather than redistribute them. The public GitHub release should default to source download instructions, hashes, analysis code and aggregate findings. Whether a particular future feature cache, fitted model or sample-level export is adapted material needs assessment before that item is released; this record does not preapprove all future outputs.

This package contains unchanged source ZIPs, project code, bibliographic/provider metadata and our QC summaries. Source dataset rights remain separate from rights in the project's own code and prose. The archived literature copies and movement image are not redistributed.
