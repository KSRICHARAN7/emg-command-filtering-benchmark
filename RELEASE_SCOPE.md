# Public release scope

Version0.11.0 contains original analysis code,51 synthetic/unit checks, a nine-dependency frozen protocol, exact-source acquisition metadata, locked controller parameters, six analytical SVG figures and12 CSV/Markdown tables. Aggregate JSON outputs cover primary DB5,23 DB5 sensitivities, subsets and native DB2 replication. The private package additionally retains models, predictions, per-event diagnostics and two sample-level failure examples.

Excluded: original data; modified waveform/label arrays; feature arrays; fitted models; sample-level predictions; E01/E02 sample traces/figures and selection files; temporary source-download files; private Drive URLs; local account information; archived third-party article copies. No user email or credential is part of this release.

The claim-evidence table is preserved from the complete evidence packet. E02 refers to a withheld private trace; T08 is supplied as a role-level aggregate only. Public F03/T03 demonstrate the correct/wrong/zero aggregate decomposition. Archived mentions of Step11 preparation describe status at that historical time. The authoritative current public status is README.md and release_validation/.

The original dated protocol and metadata remain byte-identical. config/DB2_replication_v1.0.json is a later DB2 adaptation; its inherited frozen_at text refers to the original DB5 plan and must not be interpreted as a separately preregistered DB2 protocol. The pre-final DB2 selection lock is summarized by settings/hash in config/locked_settings.json.

Original code/documentation use MIT; third-party metadata/data keep their own terms. Public numerical outputs are analytical findings. No source-data relicensing or creator endorsement is claimed.
